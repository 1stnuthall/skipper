# Skipper
Skipper is a bot for Slack whose sole purpose is to make managing Scouting a lot easier, with the ability to query and update some areas of OSM and keep your group communicating better.

# In development
This project is very much still under development

# Features
This project features the following:
- Slack Integration
- Scheduled Tasks
- Slash Commands for quick access
